# Intelligent Embedded Room Monitoring and Automation System

## Project Overview

This project focuses on designing and developing an intelligent embedded system capable of monitoring room conditions and automating selected household functions.

The system uses an ESP32 microcontroller as its central processing unit and integrates multiple sensors and output devices to achieve environmental monitoring, motion detection, and basic home automation.

## Objectives

- Monitor room temperature and humidity.
- Detect human movement inside a room.
- Monitor ambient light intensity.
- Display relevant environmental information.
- Automate selected household functions.
- Develop practical skills in embedded systems, sensors, actuators, and microcontroller programming.

## Hardware Components

- ESP32 DevKit
- DHT22 Temperature and Humidity Sensor
- PIR Motion Sensor
- LDR Light Sensor
- OLED Display
- Ultrasonic Sensor
- Servo Motor
- Relay Module
- Buzzer
- LEDs and Resistors
- Breadboard and Jumper Wires
- 5V Power Adapter

## Software and Tools

- Arduino IDE
- Embedded C/C++ (Arduino framework)
- Git and GitHub
